# PhotoCraft collaboration (native experimental)

Open a document, then **Window → Collaboration…**. Set your name/color/icon, create a room and share its join code. Another native PhotoCraft instance opens a document, enters that code (and optional password), and joins. Its existing documents are preserved; the received room document opens separately. The default public signaling service is `https://photocraft-mp.theseanlavery.workers.dev`. For local-only testing, choose `http://127.0.0.1:5548`; that loopback service starts automatically when creating a room. Run `cargo run -p photocraft-room-server` for a standalone service; `PHOTOCRAFT_ROOM_BIND` changes its bind address. Use HTTPS and operator-managed STUN/TURN for Internet deployment; `PHOTOCRAFT_ICE_SERVERS` is a JSON array of WebRTC ICE server configurations. The public playtest address is backed by a Rust Cloudflare Worker and a native room service through Cloudflare Tunnel; the origin operator must keep the room service running.

The host owns admission and canonical document order. Brush, Eraser and Pencil strokes stream in bounded sequenced chunks with complete resolved brush settings, sampled tips/textures, deterministic seeds, pressure, tilt, rotation, stylus wheel, timestamps and smoothing zoom. Each artist chooses their own tool, active layer and selection. Stroke clipping captures only its author's selection. Initial join transfers a lossless baseline and complete retained author journal in a bounded checkpoint; routine painting sends inputs, not canvas pixels. Cursors use a separate disposable data channel so they never occupy the document operation log.

Undo/redo affects only the requesting artist's edits, even after other artists add many newer edits. Layer creation, transforms, filters, text, shapes, masks/channels, retouching and other document commands use a host-ordered transaction path. Commands capture their author's target layers, private selection and required tool inputs. Files, fonts, plug-ins, clipboard and cross-document sources resolve on the initiating artist; bounded native metadata and changed tile/blob resources carry those results. Semantic commands replay deterministically for author undo. Layer creation remains as an empty structural prerequisite when another artist has added dependent artwork. Disjoint strokes use sparse dirty-tile updates. Overlapping strokes and undo rebuild the affected layer in canonical stroke-start order so noncommutative blending converges. This preserves other artists' edits without asking them to resolve ordinary overlaps.

Room chat, optional cursor names/icons/colors, cursor and note display toggles, collapsible sticky notes, and shared/personal layer visibility are available in the collaboration window. Select **Enable voice**, grant native microphone access if requested, and hold **Hold to talk** to transmit. Voice uses bounded 20 ms, 16 kHz mono µ-law frames over a disposable encrypted WebRTC data channel; this is PhotoCraft-to-PhotoCraft audio, not browser RTP interoperability. No voice is transmitted while the button is released.

## Cloudflare playtest service

The standalone Rust room server can issue temporary Cloudflare STUN/TURN credentials automatically. Set `PHOTOCRAFT_TURN_CONFIG` to a private JSON file containing `key_id` and `api_token`; keep it outside the repository with owner-only permissions. `POST /ice` requires an admitted room's code, peer and bearer token. Forged, expired, kicked and departed members are rejected before credential generation. Responses use `Cache-Control: no-store`; credentials live for 24 hours and are cached per participant for one hour. Rejoin before a session exceeds 24 hours. Provider failures are visible and do not silently downgrade a public room to local-only connectivity.

Run the room server on loopback and point `cloudflared tunnel --url http://127.0.0.1:PORT` at it. Only this signaling/download service is exposed; never tunnel PhotoCraft's automation control port. A Quick Tunnel is a temporary playtest: its hostname changes when restarted and the operator's Mac must stay awake. It is not an always-on Cloudflare deployment. A stable named tunnel or hosted Rust service is the next deployment step.

The UI and engine commands default to `https://photocraft-mp.theseanlavery.workers.dev`. Distributors can build with `PHOTOCRAFT_DEFAULT_SIGNALING_URL=https://your-public-host` to override that address. The long-term TURN token is **never** included in client builds. Explicit `PHOTOCRAFT_ICE_SERVERS` remains an operator override; without it, admitted clients fetch `/ice` automatically. Legacy loopback servers without `/ice` keep local connectivity. The browser still lacks a peer adapter.

`PHOTOCRAFT_PLAYTEST_DOWNLOADS=/private/dedicated/download-folder` optionally serves only that folder at `/downloads`. Keep credentials, logs and private documents out of it. Use the same multiplayer build for everyone.

Internet acceptance:

```sh
PHOTOCRAFT_PLAYTEST_URL=https://your-public-host cargo test -p photocraft-collab --features native --test webrtc cloudflare_public_signaling_and_forced_relay_all_channels -- --ignored --nocapture
PHOTOCRAFT_PLAYTEST_URL=https://your-public-host PHOTOCRAFT_RTC_RELAY_ONLY=1 cargo test -p photocraft --bin photocraft public_cloudflare_bridge_draw_chat_late_join_and_undo -- --ignored --nocapture
```

The first test routes SDP over the actual public HTTPS service, excludes host candidates, and verifies all three encrypted data channels bidirectionally through Cloudflare TURN. The second exercises the native application bridge: bootstrap, two-author drawing, chat, late join, preserved guest documents and personal undo. Native microphone/speaker interaction remains a separate physical check; Discord voice is recommended for the first playtest.

## Current boundaries

This is a native collaboration implementation. The shared protocol builds for wasm, but browser peer/microphone adapters are not implemented. Document mutations route through the shared transaction path. Preferences, presets, tool choices, selections, Quick Mask editing, view controls and local exports stay private. Local tabs and Smart Object contents remain editable; saving or closing edited contents publishes the parent object transaction. Join leaves unrelated local documents intact and pins the room document. A departing host stops the room and leaves each participant's received document available locally. Automatic host migration is not implemented. Brushes larger than 1024 pixels and selections covering more than one megapixel retain local previews and publish their completed document transaction; these cases do not stream remote previews. Physical microphone/speaker interaction and Internet connectivity with the deployed service is covered by the opt-in acceptance tests below; physical microphone/speaker interaction remains unverified.

At most 64 participants, 4096 archived document edits, a 480 MiB checkpoint history including its baseline (with a separate 64 MiB evicting transport log), 65536 samples per stroke, 256 samples per chunk, a 512 MiB serialized bootstrap/transfer and 512 MiB aggregate reassembly are admitted. Brush/selection work also has allocation and rendering bounds. Late joins receive a fresh document checkpoint with the complete retained author journal, redo entries and in-flight stroke chunks. CBOR preserves binary asset data; 16 KiB fragments share one encoded buffer across recipients. Recomposition of large overlapping histories remains a performance limitation. Different PhotoCraft builds must use the same deterministic renderer; protocol-version mismatches are rejected, but a complete renderer build fingerprint handshake remains future work.

## Reproducible verification

`cargo test -p photocraft-collab --features native --test webrtc` exercises real encrypted data channels, admission/password checks and HTTP-signaled workers. The ignored scale tests additionally exercise 32 links/32 workers and direct RTC delivery while signaling is unavailable. `cargo run -p photocraft-room-server --features doodles --bin collaboration-doodles -- /absolute/evidence` renders 32 different seeded artists over 31 real RTC links and verifies pixel convergence. To join two native windows with 30 additional drawing bots, use `collaboration-doodles --join http://127.0.0.1:5548 ROOM_CODE - /absolute/evidence` (replace `-` with the room password when set). Native bridge tests cover checkpoint transfer, document preservation, streamed edits, chat and per-author undo. See [research](collaboration-research.md) for protocol and raster-editing references.
