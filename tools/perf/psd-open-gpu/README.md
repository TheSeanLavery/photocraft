## Workload

Generate the image separately, then generate two immutable 7360x4912 PSDs: three dense textured raster layers and a complex eight-leaf case with cropped layers, alpha, masks, blends, hidden data, a group and an adjustment. Native source is 1536x1024 generated by image_gen; nearest-neighbor scaling is explicitly recorded. This is a P44-class workload, not the original generated P44 fixture. Keep generated assets and PSDs outside Git and record hashes/provenance.

Build tools:

```sh
CARGO_TARGET_DIR=target/agent-psd-open cargo build --release --manifest-path tools/perf/psd-open-gpu/Cargo.toml
```

The manifest is independent to avoid building the entire UI. It uses release opt-level 3, thin LTO and one codegen unit. Historical builds add `--features legacy-compositor`; this only hides cache APIs absent in the old compositor.

Generate once:

```sh
target/agent-psd-open/release/psd-open-fixture generate SOURCE.png FIXTURE_DIRECTORY
```

Import phase diagnostics and pixel signatures:

```sh
target/agent-psd-open/release/psd-open-fixture bench FIXTURE.psd REPORT.json 3
```

P44-style GPU path:

```sh
target/agent-psd-open/release/psd-open-gpu-experiment FIXTURE.psd REPORT.json 3 cache-on fresh
```

`fresh` creates a new compositor outside the timed region for each sample, removing prior-document texture accumulation. `shared` intentionally reproduces the original repeated-open residency behavior; do not combine lifecycle results. `cache-off` is available on modern source as a diagnostic. Keep repetitions equal when comparing shared mode because resident memory grows with repetitions.

Disk reads, image generation, GPU initialization, readback, hashing and previews are outside measurements. Total measures import + new Session/document admission + full-canvas GPU encode/submit/wait. One cold sample is separate, with subsequent raw samples retained. ABBA pairs use the same fixed PSD, adapter, lifecycle and repetitions. Results were measured on a shared Apple M1 Max desktop with other workloads; absolute numbers vary and are not the hosted M1 runner numbers in the PR.

## Correctness

Require identical fixture hashes/bytes and complete imported structure/raster/mask/CPU crop hash records. Validate representative GPU crops at top-left, mask, group and group-mask locations against the CPU oracle, within one 8-bit level plus float tolerance. Unit/integration tests cover U8/U16/F32, negative origins, tile boundaries, transparency/default pixels, missing/damaged channels and deterministic warnings. Before/after files in plan/psd-open-experiment/results retain all samples and checks.

## Changes

1. Native decode of a raster layer's independent channels in a bounded set of workers.
2. RGB8 planar channels assembled in final tiles, avoiding the whole-image interleaved allocation/copy.
3. General interleave workers own disjoint output slices, eliminating temporary band allocations/copies. Other formats preserve the existing conversion semantics; wasm remains sequential.

No timing assertions belong in correctness tests. Do not update a baseline to hide failed correctness or a regression.

## Linux iteration

Use a dedicated snapshot directory and the same flags for every reference and candidate. The Linux run used Rust 1.99, release opt-level 3, `CARGO_PROFILE_RELEASE_LTO=false`, `CARGO_PROFILE_RELEASE_CODEGEN_UNITS=16`, and `RUSTFLAGS="-C target-cpu=native"`. Native binaries are specific to that CPU. Reuse fixed files; alternate version order and reverse it in a second batch, with equal warmup/repetition counts. Preserve raw timings and complete import signatures.

The retained additional optimization validates RLE packet lengths before initializing the final output, then decodes row bands into disjoint slices, with at most four workers per channel. The fixed-block packing experiment and worker-count override were discarded. See the local `plan/psd-open-experiment/linux-report.md` and raw Linux JSON evidence; no timing assertion is used as a correctness gate.
